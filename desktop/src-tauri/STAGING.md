# Сборка ресурсов установщика (`desktop/src-tauri/staging/`)

Каталог `staging/` — источник для `bundle.resources` в `tauri.conf.json`. Он **генерируется**
перед `npx tauri build` и **не коммитится**. В него кладётся только то, что должно лежать рядом
с `.exe`: собранное приложение и рантайм движка картинок. Веса моделей сюда НЕ кладутся —
они качаются при первом запуске, иначе установщик распух бы на десятки гигабайт.

## Как собрать

Из корня репозитория, после `cargo build --release` и `cd frontend && npm run build`:

```bash
scripts/stage.sh
```

Скрипт создаёт `staging/` заново, поэтому лишнего от прошлой сборки в установщик не попадёт.
